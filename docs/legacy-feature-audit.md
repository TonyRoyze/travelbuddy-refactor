# Legacy feature coverage audit

See [the F001–F014 Phase 1 audit](phase-one-feature-audit.md) for the feature-by-feature verification and the search/gallery gaps restored on 21 October 2026.

Compared the legacy Next.js routes and feature components in `legacy/src/` with the Vite routes and feature modules in `src/`. The new app does **not** have full feature parity. It covers the first milestone from the refactor plan, while several legacy features were explicitly deferred.

| Legacy capability                                                  | New app coverage                                                                                     | Status                                                                                                           |
| ------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| Home, package discovery, categories, keyword and price filters     | `/`, `/search`                                                                                       | Present for published packages, including autocomplete, date/duration filters, Live Now, sorting and pagination. |
| Experience details and availability                                | `/experience/$id`                                                                                    | Present, including live slots, package details, and booking/chat entry points.                                   |
| Guide and buddy discovery, guide profiles, map search              | Legacy `/nearby`, `/buddy/$id`                                                                       | Live map/list discovery is now at `/nearby`; public Buddy/Guide profiles are at `/buddy/$id`.                    |
| Destination pages                                                  | Legacy `/destinations`                                                                               | Partial; the new home page has destination links that lead into search, without dedicated destination pages.     |
| Email sign-in, registration, recovery, OAuth, onboarding, sign-out | `/login`, `/register`, `/forgot-password`, `/reset-password`, `/register/complete`, `/auth/callback` | Present. OAuth buttons are limited to providers enabled in the current Supabase configuration.                   |
| Saved experiences                                                  | Legacy `/saved` and save controls                                                                    | Missing; explicitly deferred.                                                                                    |
| Cart and checkout                                                  | Legacy `/cart`, `/checkout`                                                                          | Present; account-specific persistent cart and atomic multi-item checkout.                                        |
| Booking confirmation, history, detail, cancellation                | `/confirmation/$id`, `/bookings`, `/booking/$id`                                                     | Present. Booking writes use database availability, ownership, price, and cancellation checks.                    |
| Inbox, direct/package conversations, messages                      | `/inbox`                                                                                             | Present. Existing direct and request conversations remain readable; package threads can be started and reused.   |
| Public traveller request board, request creation, private replies  | Legacy inbox request board                                                                           | Missing; explicitly deferred.                                                                                    |
| Custom packages/offers in existing conversations                   | Legacy inbox offer messages                                                                          | Existing offers remain readable; creating new custom offers is missing with request replies and package editing. |
| Account overview and role onboarding                               | `/account`, `/register/complete`                                                                     | Present; restored overview, profile editing, account access, onboarding and provider controls.                   |
| Profile settings, profile photos/video, display preferences        | Legacy `/account/settings` and profile components                                                    | Present; role-specific fields, profile photos, introduction clips and light/dark/system preferences.             |
| Buddy package authoring, schedule editor, capacity controls        | Legacy `/account/packages`                                                                           | Present; Buddy-only package list/editor, uploads, schedules, reserved places, drafts and publishing.             |
| Reviews                                                            | Legacy `/reviews` and experience review sections                                                     | Missing; explicitly deferred.                                                                                    |
| Support/FAQ and secondary information pages                        | Legacy `/support` and other secondary routes                                                         | Missing; secondary pages were deferred.                                                                          |
| Development test-account switcher                                  | Legacy `/test-accounts`                                                                              | Missing from the new app.                                                                                        |

The most consequential gaps for feature parity are saved experiences, public requests and replies, reviews, and support pages. The current implementation matches the agreed booking and package-chat milestone, not the complete legacy product.
