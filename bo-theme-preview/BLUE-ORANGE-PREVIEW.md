# Blue & Orange theme preview

This directory contains the standalone Next.js design currently developed on `main`. It is included on a branch based on `dev` for review; its blue/orange palette and illustrated hero are now adapted into the Vite application at the repository root. The root app retains its TravelBuddy identity and production features; this directory remains a standalone design reference.

Run `pnpm install` and `pnpm dev` from this directory. Authentication and catalog database features require the configuration described in `.env.example` and the project documentation.
